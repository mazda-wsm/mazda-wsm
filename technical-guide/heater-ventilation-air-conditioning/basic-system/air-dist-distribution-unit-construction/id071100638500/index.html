AIR DIST (DISTRIBUTION) UNIT CONSTRUCTION

id071100638500

• Composed of the following parts:

  • Airflow mode actuator - Airflow mode main link - Airflow mode door

Airflow Mode Door Operation

• The airflow mode doors move to the OPEN-VENT, OPEN-BI-LEVEL, OPEN-HEAT, VENT HEAT, HEAT/DEF or DEFROSTER position, depending on the position of the airflow mode control dial. As a result, the airflow mode changes.
